# Gestor de Actividades - Jetpack Compose

Aplicación Android desarrollada con **Jetpack Compose** que demuestra el
manejo de estado (`remember`, `mutableStateOf`) y **state hoisting**
mediante un gestor sencillo de actividades.

## Funcionalidades

- ➕ Agregar una actividad
- 👀 Ver la lista de actividades
- 🔄 Cambiar el estado de una actividad
- 🗑️ Eliminar una actividad
- 🔎 Filtrar actividades con un `LazyRow`
- 📋 Visualización de la información en una `LazyColumn`

## Tecnologías

- Kotlin
- Jetpack Compose
- Material 3
- Android Studio
